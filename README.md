# Тетрис для Linux 🐧

Классическая игра Тетрис, написанная на Python с использованием графического движка Pygame. Специально адаптирована под Linux!

## 🚀 Особенности игры:
* **Расширенное поле:** Увеличенный стакан (14 столбцов вместо 10) для более интересного геймплея.
* **Полноэкранный режим:** Игра автоматически открывается на весь экран. Выход из игры по кнопке `ESC`.
* **Управление:** Плавное и быстрое падение фигур при зажатии стрелки вниз.
* **Сохранение рекорда:** Игра автоматически запоминает твой лучший результат.

## 📦 Как установить и играть:
1. Скачай готовый пакет **`tetris-game.deb`** из раздела **Релизы** (справа).
2. Дважды кликни по скачанному файлу в проводнике и нажми кнопку **«Установить»** в открывшемся окне.
3. Найди «Тетрис на Python» в главном меню всех приложений твоего Linux и запускай!
